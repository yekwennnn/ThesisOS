# ThesisOS · ThesisDiff 原型界面

ThesisOS V0（ThesisDiff）的网页原型：为没有 AI 使用经验的长期价值投资者设计，黑白极简风格。

## 快速开始

需要电脑装有 Node.js 18 及以上版本（https://nodejs.org 下载 LTS 版即可）。

两种方式任选其一：

- **双击 `start.command`**（macOS）：自动启动并打开浏览器。
- **命令行**：在本目录执行 `node server.js`，然后浏览器打开 http://localhost:8787

停止服务：关掉终端窗口，或按 `Ctrl + C`。

## 功能

- **工作台**：管理持仓、观察、研究中的公司，每家公司对应一张投资逻辑卡。
- **搜索式创建**：输入公司名称或代码任一项，从候选中点选即可，无需同时填写。
- **投资逻辑卡（Thesis Card）**：一句话逻辑、关键假设、证伪条件、最强反方、估值锚、未知问题；每次更新生成新版本，历史版本完整保留。
- **材料**：粘贴财报、业绩会纪要、公告全文（PDF 请先复制文本）。
- **Thesis Diff**：选一份材料，AI 逐条比对新旧证据，输出总体判断、假设变化、管理层言行对比、反方解释、待验证问题与修改建议；由你决定接受、修改后接受、拒绝或暂缓。
- **引导式流程**：公司页顶部显示进度（建立逻辑卡 → 加入材料 → 生成报告），每步完成后自动引导到下一步。
- **设置**：选择大模型（Kimi / DeepSeek / OpenAI / 通义千问 / 智谱 / 豆包 / 自定义 OpenAI 兼容接口）与金融数据源（东方财富 / Tushare Pro / Wind 万得 / 演示数据），支持一键测试连接。
- **演示模式**：默认开启，不需要任何 API Key 即可完整体验全部流程（输出为示例内容）。

## 数据源说明

| 数据源 | 需要密钥 | 覆盖 |
| --- | --- | --- |
| 东方财富 | 否 | A 股 / 港股 / 美股实时行情 |
| Tushare Pro | Token | A 股 / 港股日线 |
| Wind（万得） | 否（需本机已安装配置 Wind 接口） | A 股 / 港股 / 美股行情截面 |
| 演示数据 | 否 | 内置虚构行情 |

Wind 源通过本机 `wind-mcp-skill` 的 CLI 取数（`~/.agents/skills/wind-mcp-skill`）；未安装或未授权时会在界面给出明确提示。证券搜索（名称/代码 → 候选）统一走腾讯公开联想接口。

## 数据与隐私

- 全部数据（公司、逻辑卡版本、材料、报告、密钥）保存在本机 `src/data/` 目录，不会上传到任何第三方。
- 密钥明文保存在 `src/data/settings.json`，请妥善保管本机；`src/data/` 已加入 `.gitignore`，不会被提交到 git。
- 删除 `src/data/` 即可清空全部数据重新开始。

## 目录结构

```text
src/
├── server.js        # 零依赖 Node 服务器（静态托管 + API + 大模型/行情代理）
├── public/          # 前端（index.html / style.css / app.js，无构建步骤）
├── prompts/         # 本网页端使用的 AI 提示词模板
├── start.command    # macOS 双击启动脚本
└── data/            # 运行后生成：本地数据与设置（已 gitignore）
```

## 当前限制（V0 原型）

- PDF 不直接解析，请复制文本后粘贴。
- 超长材料送入模型前会截断到约 6 万字符。
- Tushare 行情支持 A 股与港股；美股行情建议用东方财富源。
- 演示模式的「AI 输出」为模板示例，仅用于熟悉流程；真实分析需在设置中接入大模型。
